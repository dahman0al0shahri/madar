## Language and historical records

English is the primary language of repository-facing documentation. Arabic course names and learning content retain their original language.

Dated documents in this directory and the repository root record earlier decisions or implementation work. They remain in their original locations and language to preserve references and context. They are not necessarily complete descriptions of the current application.

The historical [appearance reference, in Arabic](APPEARANCE_AR.md) documents an earlier visual system; it does not authorize changes to any course interface. The original [course integration policy, in Arabic](../COURSE_INTEGRATION.md) remains the source for detailed project-specific requirements.

When an older document conflicts with current behavior, verify the code and the applicable decision before updating the documentation.
