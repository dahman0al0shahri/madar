# خلفية Windows الداكنة — 27 أكتوبر2026

التوضيح المعتمد من المستخدم: الخلفية نفسها تعبّر عن نظم التشغيل، لا الاكتفاء بتعديل الشعار. اختار صراحة «خلفية مستوحاة منWindows، بموجات ضوء داكنة متحركة». أضيف رسمSVG أصلي من ثلاث طبقات نسيج ضوئي فحمي وأزرق، يتحرك ببطء خلف الرمز والنوافذ. رمز السيرفر والكلمة الصحيحة Pa$$w0rd وخطوات المهارات باقية. لا نسخ لملف خلفية Windows تجاري، ولا صورة جديدة أو تحميل فيديو.

زر الحركة يوقف الخلفية والمدار في مكانهما دون إعادة رسم سطح المكتب، ثم يستأنفهما. CSS يحترم prefers-reduced-motion. البحث لهذه المهمة: MDN animation-play-state يوضح الاستئناف من الموضع المتوقف؛ W3C Pause Stop Hide يدعم توفير التحكم بالحركة المستمرة. الروابط:
- https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-play-state
- https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html

هذه زخرفة للمحاكاة لا حالة تشغيل Windows ولا مقياس أداء للطالب. الاختبارات مصطنعة محلية؛ لا تعديل لسجل تعلم.
