# هوية مدار الداكنة للمختبر

طلب المستخدم إزالة المساحات الفاتحة داخل النوافذ والحقول، مع ألوان داكنة موزونة ولمسات مدار. هذا تعديل عرض لأول ثلاثة دروس وسبع مهارات، لا إضافة خطوات أو تغيير محتوى Windows.

- خلفية فحمية متدرجة، أثر مداري خافت ثابت، وأيقونات SVG مضمّنة بدل الرموز المختلفة بين الأجهزة؛ لا مكتبة أو صور أو تنزيل إضافي.
- النوافذ والمعالجات والحقول والقوائم والحوارات كلها داكنة، مع نصوص رمادية فاتحة وحدود واضحة وتلوين هادئ للتركيز والتحديد.
- النافذة الأمامية تتميز بدرجة العنوان وحدودها وظلها؛ تحديث التمييز عند النقر لا يعيد إنشاء الحقول ولا يبدل قيمها.
- ألوان النجاح والتنبيه محدودة بمساحاتهما؛ لا توهج متحرك أو زخارف تتحرك خلف القراءة. يحترم prefers-reduced-motion. لا ادعاء طبي بأن الثيم يمنع إجهاد العين.
- بقيت مواضع أسماء أدوات Windows ومسارات الدروس. هذه هوية مدار البصرية، وليست نسخة ألوان أصلية من Windows Server 2012.

مراجع تصميم مقروءة في هذه الدفعة: [W3C Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) لحدود التحكم والتركيز، و[Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) لاحترام تقليل الحركة. القياسات الجزئية ليست تدقيق مطابقة WCAG كاملًا.

التحقق: المعالج ونافذة الاعتماد ومدير Hyper-V والإعداد واختيار الملف بالمتصفح، قياس الألوان المحسوبة للحقول والأسطح، وفحص 1280×900 و390×844 دون تجاوز أفقي للصفحة. أعيدت فحوص الربط الثمانية بعد تغيير الأيقونات؛ اختبارات المنطق السابقة لم تعد لعدم تغير النموذج. الصور والتقرير والحزمة في work/os1-dark-20261027. الرفع يبقى مؤجلًا وفق توجيه المستخدم السابق بعد فشل الاتصال؛ لا يثبت هذا الملف نشرًا.
