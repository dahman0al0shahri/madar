الحفظ في مَدار

أعطال تحتاج متابعة

كل خدمة في بطاقة واحدة، مع عدد الاستجابات الفاشلة. «اطلعت عليه» لا يعني إصلاح العطل؛ نجاح عملية حفظ لاحقة يغيّر الحالة إلى «عاد الحفظ».

مصادر الدروس

روابط الفيديو

يفحص روابط المحتوى المنشور عند طلبك. «متاح للفحص» تعني استجابة بيانات الفيديو؛ لا تضمن تشغيله في كل جهاز أو بلد. نتيجة قديمة؟ أعد الفحص.

حدود المتابعة وحماية الخصوصية
  • نرصد أخطاء الخادم أثناء محاولات الحفظ الجديدة. أخطاء الإدخال، انتهاء الدخول وتعارض التعديلات ليست أعطال خدمة.
  • التنبيهات داخل مساحة المالك؛ لا تُرسل رسائل بريد أو إشعارات عند إغلاقها. فحص الفيديو يبدأ بزر الفحص، وليس مهمة مستمرة في الخلفية.
  • انقطاع جهاز الطالب قبل وصول الطلب أو توقف الموقع وقاعدة البيانات بالكامل قد لا يُسجل. تعذّر قراءة اللوحة يظهر كخطأ، ولا يعني أن الموقع سليم.
  • لا نحفظ نص ملاحظات الطالب أو إجاباته أو هويته في سجل الأعطال. نحفظ اسم الخدمة والعداد والتواريخ وآخر حالة؛ لا نمحو العطل السابق عند عودة الحفظ.
  • عدد الاستجابات الفاشلة قد يشمل محاولات إعادة الحفظ للشخص نفسه؛ ليس عدد طلاب متضررين. لا توجد مراقبة لزمن الانقطاع.
  • تعذّر فحص YouTube أو تقييده لا يثبت حذف الفيديو؛ افتح المصدر وراجعه قبل استبداله.
