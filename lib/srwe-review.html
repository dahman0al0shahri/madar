فهم Inter-VLAN Routing

VLAN — Virtual Local Area Network: شبكة محلية افتراضية تفصل أجهزة Layer 2 إلى مجالات بث مستقلة. Inter-VLAN Routing هو نقل الحزم من شبكة VLAN إلى أخرى بواسطة جهاز Layer 3. وجود Trunk، أي وصلة تحمل حركة عدة VLANs، لا يوفّر التوجيه وحده.

الحل / Methodكيف يعمل؟متى نميّزه؟
Legacyمنفذ Router فعلي لكل VLAN؛ عنوان المنفذ بوابة الحواسيب في شبكتها.يستهلك المنافذ، وقابلية توسعه ضعيفة.
Router-on-a-Stickمنفذ Router واحد، ووصلة 802.1Q Trunk، وواجهة فرعية لكل VLAN مطلوب توجيهها.مناسب في سياق الشابتر للشبكات الصغيرة والمتوسطة.
Layer 3 Switch + SVIواجهة SVI لكل VLAN، والتوجيه داخل Switch.أسرع وقابل للتوسع، مع تكلفة أعلى وفق المقارنة التعليمية.
PC1 · VLAN 10→Switch↔ Trunk ↔Router
G0/0/1.10 / .20→PC2 · VLAN 20

كيف تمر الحركة؟ / Packet path

  1. يرسل PC1 الحركة المتجهة إلى شبكة أخرى عبر بوابته الافتراضية في VLAN 10.
  2. يحمل Trunk الإطار إلى Router بوسم VLAN 10. تستقبله الواجهة الفرعية المرتبطة بهذه VLAN.
  3. يحدد Router واجهة الخروج وفق شبكة عنوان IP للوجهة.
  4. يعاد تغليف الإطار بوسم VLAN 20 إذا كانت واجهة الخروج موسومة، ثم يعود عبر المنفذ الفعلي نفسه إلى Switch ويصل إلى PC2.

Subinterface: واجهة منطقية برمجية تتبع واجهة فعلية. رقمها مثل G0/0/1.10 لا يحدد VLAN وحده؛ الأمر encapsulation dot1q 10 هو التعيين الفعلي. مطابقة الرقمين عادة تنظيمية.

تمييز مهم

Default Gateway هي عنوان واجهة Layer 3 في شبكة الحاسب، وليست عنوان الشبكة أو عنوان البث. عنوان SVI الإدارة على Layer 2 Switch يتيح الإدارة ولا يحوّل الجهاز وحده إلى جهاز توجيه.

ملاحظة المادة: يذكر الشابتر أن Router-on-a-Stick لا يتوسع بعد 50 VLAN في سياق المقارنة. لا نعامل الرقم حدًا ثابتًا لكل منصة؛ الفكرة الأساسية أن حل Layer 3 Switch أنسب للتوسع.

لماذا STP؟ وكيف يُنتخب الجذر؟

Spanning Tree Protocol (STP): يمنع حلقات Layer 2 مع الاحتفاظ بكابلات بديلة. الحل هو حجب تمرير بيانات المستخدم على منافذ مختارة، وليس حذف الكابلات. عند تغير الشبكة يعاد الحساب وقد يعمل منفذ كان محجوبًا.

قد تسبب الحلقة عدم استقرار جدول MAC، وعاصفة بث، وامتلاء الوصلات وارتفاع استخدام المعالج. IPv4 يملك Time to Live (TTL) وIPv6 يملك Hop Limit، لكن إطار Ethernet لا يملك حد قفزات مكافئًا ينهي دورانه. لا يعني ذلك أن كل Broadcast عطل؛ ARP Request مثال طبيعي، أما العاصفة فزيادة ترهق الشبكة.

Unknown Unicast: إطار بعنوان MAC وجهة غير معروف في جدول Switch. ينشر داخل VLAN عبر منافذ التمرير المؤهلة عدا منفذ الدخول. يبقى عنوان وجهته Unicast؛ لا تخلطه بعنوان Broadcast.

ترتيب اختيار البنية / Election sequence

Root Bridge→Root Ports→Designated Ports→Alternate Ports

BPDU — Bridge Protocol Data Unit: رسالة تحكم تحمل معلومات STP. BID — Bridge ID: معرف يستخدم للمفاضلة بين Switches، ويتكون من Bridge Priority وExtended System ID وMAC Address.

المعلومةالقاعدة
Root Bridgeيفوز أقل BID في نسخة STP.
Bridge Priorityالافتراضي 32768؛ من 0 إلى 61440 بزيادات 4096؛ الأقل أفضل.
Extended System IDيمثل VLAN ويضاف إلى الأولوية: 32768 + VLAN 20 = 32788.
تعادل الأولوية في VLAN نفسهايفوز MAC الأقل، بالمقارنة الست عشرية.
Root Portمنفذ واحد لكل Switch غير جذري في كل نسخة؛ أفضل طريق إلى الجذر.
Designated Portطرف المقطع الذي يقدم أفضل طريق للجذر؛ منافذ الجذر العاملة في المثال Designated.
Alternate Portطريق بديل لا يمرر بيانات المستخدم في البنية الحالية.

إذا كانت أولوية S1 تساوي 24576 وأولوية S2 تساوي 32768 في VLAN واحدة، يفوز S1 ولو كان MAC لديه أعلى. لا نصل إلى مقارنة MAC إلا بعد تساوي جزء الأولوية ومعرف VLAN.

التوافق: منافذ تدعم EtherChannel، ونوع وسرعة وDuplex متوافقة. أعضاء Access في VLAN واحدة، وأعضاء Trunk بإعداد Native VLAN وقائمة Allowed VLANs متوافقة. لا يشترط تجاور أرقام المنافذ. لا تخلط Fast Ethernet وGigabit Ethernet داخل المجموعة في السيناريو التعليمي.

توضيحات لمنع الالتباس

  • تسمية Subinterface لا تفرض رقم VLAN؛ نعتمد أمر encapsulation.
  • Routed Port ليس شرطًا للتوجيه المحلي بين SVIs؛ يستخدم في مثال الاتصال بجهاز Layer 3 آخر.
  • لا نخلط Short وLong Path Cost، ولا نفترض أن كل RSTP يستخدم القيم الطويلة.
  • EtherChannel لا يعطل STP، ولا يجمع منافذ غير متوافقة لمجرد تفعيل on.
  • الأعداد والافتراضات الخاصة بالمنصات في الشرائح موسومة بسياق المادة، وليست حدودًا عامة لكل جهاز حديث.
